# RaceCar (Авто Мастер) 🏎️💨

**RaceCar** — это динамичная игра-мердж (Merge Game), где вы собираете коллекцию автомобилей, улучшаете их путём слияния и участвуете в автоматических гонках для добычи ресурсов. Проект разработан на Unity и оптимизирован для мобильных устройств и платформы Яндекс Игр.

## 🎮 Ключевые особенности

- **Интуитивное управление**: перетаскивайте автомобили пальцем или мышью.
- **Система слияния (Merge)**: объединяйте два одинаковых автомобиля, чтобы получить новую, более мощную модель.
- **Прогрессия**: открывайте всё более высокоуровневые и редкие машины.
- **Экономика**: собирайте ресурсы во время автоматических заездов, покупайте ускорители и новые автомобили в магазине.
- **Подарки и бонусы**: получайте награды за активность.

## ⚙️ Механики игры

### 🚗 Гараж и перетаскивание
Все ваши автомобили находятся в гараже. Вы можете свободно перемещать их по игровому полю простым перетаскиванием — передвиньте машину, чтобы начать гонку или объединить её с другой.

### 🔀 Слияние автомобилей (Merge)
Главная механика прогресса. Чтобы улучшить автомобиль:
1. Возьмите один автомобиль и перетащите его на **точно такой же**.
2. Две машины сольются и исчезнут.
3. На их месте появится **новая, улучшенная модель** с более высокими характеристиками.
4. Повторяйте процесс, чтобы открыть все модели в игре!

### 💰 Ресурсы и гонки
Автомобили автоматически ездят по круговой трассе. За каждый круг вы получаете:
- **Монеты** — основная валюта для покупок.
- **Подарки** — случайные бонусы.
- **Ускорители** — временно повышают скорость сбора ресурсов.

### 🛒 Магазин
В магазине можно потратить накопленные ресурсы на:
- Покупку новых базовых автомобилей.
- Мгновенные ускорители для слияния.
- Специальные предложения.

- ✔️ Звуковое оформление и музыка
- ✔️ Таблица рекордов (Лидерборды)
- ✔️ Полная адаптация под планшеты
- ✔️ Интеграция с Yandex SDK (реклама, авторизация)

## 🛠️ Технические детали

- **Движок**: Unity
- **Язык**: C#
- **Платформы**: WebGL (Яндекс Игры), Android, iOS
- **Интеграции**: Yandex SDK
- **Основная папка**: `Assets/`

## 🚀 Запуск проекта

1. Откройте проект в **Unity 2022.3 LTS** или новее.
2. Запустите главную сцену (`Assets/Scenes/Main.unity`).
3. Нажмите кнопку **Play** в редакторе Unity.
