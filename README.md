RaceCar (Авто Мастер) 🏁
RaceCar — это увлекательная мобильная/веб-игра в жанре "кликер" с механикой слияния (merge). Собирайте коллекцию автомобилей, улучшайте их, объединяя одинаковые модели, и участвуйте в гонках за ресурсами.

🎮 Геймплей
Игровой процесс строится вокруг трёх основных механик:

🚗 Гараж и управление
Вы начинаете игру с базовыми автомобилями в гараже. Управление интуитивное:

Перетаскивание: перемещайте машины по полю с помощью мыши или касания пальцем.

🔀 Слияние (Основная механика)
Чтобы прокачать автомобиль, просто перетащите два одинаковых автомобиля друг на друга.

В момент слияния они исчезнут, а на их месте появится новая, более мощная и крутая модель.

Повторяйте процесс, чтобы открывать всё более высокоуровневые и редкие автомобили.

💰 Сбор ресурсов
Автомобили автоматически ездят по кругу и собирают ресурсы.

Во время заездов выпадают подарки и ускорители.

Накопленные ресурсы тратьте на ускорение слияний или мгновенное улучшение машин.

🛠️ Стек технологий
Движок: Unity

Язык: C#

Платформы: WebGL (Яндекс Игры), Android/iOS

SDK: Интеграция с Yandex SDK (реклама и соцсвязи)

🚀 Быстрый старт (Для разработчиков)
Клонируйте репозиторий:

'''bash
git clone https://github.com/exsilet/RaceCar.git
'''
Откройте проект через Unity Hub (рекомендуемая версия: 2022.3 или новее).

Откройте основную сцену в папке Assets/Scenes.

Нажмите Play для тестирования в редакторе.
